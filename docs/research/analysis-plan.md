# Statistical analysis plan, draft for preregistration

## Primary analysis

Freeze a study version, question keys, form allocation, follow-up window and withdrawal cutoff before unblinding. Use participant as the randomization unit. Count invited, consented, baseline-complete, randomized, exposed, post-test-complete, followed up and withdrawn by arm, whenever the consent terms permit those counts. Record approved sources of exclusions. Never reconstruct a withdrawn participant from an earlier export.

Define the primary endpoint as the fraction correct on a complete, objectively keyed, unaided immediate post-test. Prespecify minimum task completion and any treatment of skips. The analysis notebook uses complete forms for its descriptive baseline and post-test rates. Report missing forms by arm. Estimate a treatment-policy contrast by baseline-adjusted linear regression of participant post-test accuracy on assigned arm, baseline accuracy and randomization strata including form sequence. Use participant-level heteroskedasticity-robust uncertainty intervals, report the adjusted mean difference in percentage points and its 95% interval. Report all three group means. Specify a single primary contrast and two-sided alpha before recruitment. The notebook produces descriptive estimates; fit the preregistered adjusted model after design parameters and missingness handling are approved.

## Secondary and exploratory analyses

- Compare confidence and accuracy at each stage on a common 0–1 scale. For an item asking “how likely is your chosen answer to be correct?”, score `(confidence / 100 - correct)^2`, where `correct` is 0 or 1. Lower Brier is better. A difference between mean confidence and mean accuracy is signed calibration bias and can hide opposing subgroup errors. Draw a calibration plot of observed correctness against mean confidence in prespecified bins and show the count in each. Brier measures overall probabilistic performance as well as calibration. Omit items with ambiguous outcomes.
- For training decisions, report initial/final accuracy, initial/final confidence, revision and initial-to-final transitions using matched trials. Report denominators. For AI reliance, restrict to displays with an unambiguous recommendation and initial disagreement. Count final matches as adoption. Report explicit choice of a different option as non-adoption, and missing final choices separately. Stratify by recommendation correctness. The opportunity subset is post-randomization, so these are descriptive comparisons.
- Report response-time medians, interquartile ranges and histograms by arm and stage. Define time as server receipt of the independent answer minus task presentation. Record negative or impossible values as data-quality incidents. A long interval can include an interruption. Analyze all valid intervals and a prespecified sensitivity analysis for extreme delays. Avoid inferring attention or thinking from timing alone.
- Score written reasoning with blinded raters using three dimensions, each 0–2. **Use of evidence** ranges from absent, through identification, to correct evaluation of a relevant piece of evidence. **Inference** ranges from unsupported, through a partially valid link, to a defensible conclusion linked to evidence. **Alternatives** ranges from absent, through a plausible alternative, to an explicit discriminating observation. Use item-specific anchor examples and retain each dimension. Absent submitted text is missing. Double-score a predefined subset, estimate weighted agreement per dimension with an interval, and document adjudication. Keep raw text in restricted storage.
- Analyze delayed transfer separately. Prespecify how to address multiple secondary contrasts, for example Holm correction within a defined family. Report exploratory estimates as exploratory. For repeated trial-level models use participant and item effects appropriate to the design. Never count trials from a single participant as independent participants.

## Missingness and robustness

Report assignment denominators and prespecified missingness reasons, including dropout, skipped questions, unavailable provider and invalid item key. Compare baseline performance and missingness by arm. Complete-case estimates can be biased. Plan multiple imputation for missing post-tests under a justified missing-at-random assumption using arm, baseline, form and approved predictors. Include a shift or bounds analysis for departures from that assumption. Do not impute withdrawn records when consent requires deletion. Analyze randomized assignment regardless of exposure; any per-protocol analysis is supplementary.

## Planning sample size

Choose a smallest effect in raw accuracy points with the supervisor, estimate participant-level variability and baseline correlation from relevant pilot evidence, and document alpha, power, allocation ratio, expected attrition and multiplicity. The notebook accepts a standardized effect, alpha, power and attrition and computes a normal-approximation per-arm size for one two-sided equal-allocation comparison. It is a planning sensitivity calculation; it assumes independent participants and a common variance. The third arm also needs allocation. For final planning, simulate the actual bounded scores, item counts, assignment, repeated assessments, missingness and adjusted model. Record parameter sources and resulting power curves. If the feasible sample cannot resolve the target effect, narrow the objective to estimation or feasibility before recruitment.
